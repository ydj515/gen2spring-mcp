Managed MCP Runtime

Immutable Tool Catalog에 암호화 credential과 scoped grant를 연결하고, stateless MCP 실행을 여러 replica에서 안전하게 제공한다.

1. Control plane to data plane

Owner + Tool Catalog

OIDC owner가 Catalog, encrypted credential slot, grant policy를 선택한다.

→
Activation API

24h default, 30d max. plaintext token은 응답에 한 번만 제공한다.

→
Runtime replicas

요청마다 digest 인증 후 Catalog·policy별 stateless SDK handle로 라우팅한다.

→
Provider Egress

mTLS wire만 수신하고 public HTTP/S 80/443 destination으로만 연결한다.

생성 결과와 분리: Managed Runtime은 다운로드 ZIP의 generated Spring AI 서버를 수정하거나 그 안에 포함되지 않는다.

2. Runtime request lifecycle

1. Authenticate

/mcp/{runtimeId} 경로와 bearer token을 매 요청 검증한다. miss, wrong, expired, revoked는 동일한 401이다.

2. Apply policy

Catalog·policy checksum별 허용 Tool만 노출하고 PostgreSQL에서 audit 시작과 rate 획득을 수행한다.

3. Inject credential

허용된 호출만 Tool의 exact slot을 복호화·주입하고 bounded executor가 normalization을 수행한다.

4. Cross mTLS

runtime은 provider URL에 직접 연결하지 않고 bounded internal JSON을 provider-egress로 보낸다.

5. Resolve and connect

모든 DNS answer를 검사하고 connect-time resolver snapshot을 사용한다. redirect는 없다.

6. Complete audit

결과를 safe category와 byte count로 CAS 완료한다. credential·argument·provider body는 기록하지 않는다.
