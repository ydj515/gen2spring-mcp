1. Architecture and trust boundaries

Web은 control plane, Worker는 execution plane이다. 공개 요청, 영속 저장소, 외부 fetch, 생성 실행을 각각 별도 경계로 둔다.

핵심 invariant: Web은 Docker socket을 보지 못하고, generation container는 URL fetch egress network에 연결되지 않는다.

local mode

기존 loopback-only, 임시 저장소, 단일 process, 익명 개발 UX를 보존한다. 외부 bind와 forwarded headers를 계속 거부한다.

hosted mode

OIDC, PostgreSQL migration, private storage, Worker heartbeat, trusted proxy가 모두 유효해야 시작한다. Fallback은 없다.

2. Persistent data and job state

소유권은 internal account UUID로 고정하고, lease와 fencing token으로 retry와 stale worker를 제어한다.

account

  • UUID primary key
  • unique issuer + subject
  • created / last seen
  • email/name은 권한·저장에 미사용

specification

  • owner account FK
  • UPLOAD or URL
  • object key / checksum / size
  • sanitized source label

generation_job

  • SPEC_IMPORT or GENERATION
  • immutable request snapshot
  • lease / attempt / fencing token
  • idempotency key / request hash

job_event

  • append-only sequence
  • from / to / stage
  • safe code and summary
  • no input, secret, path, output

artifact

  • job + owner FK
  • private object key
  • type / checksum / size
  • authorized app streaming only

ephemeral URL secret

  • userinfo prohibited
  • canonical target 전체를 envelope encryption
  • terminal transition cleanup
  • never log raw URL

Canonical state

QUEUED→RUNNING→ SUCCEEDEDorFAILEDorCANCELLED
RUNNING lease expiry는 attempt가 남으면 QUEUED, 소진되면 FAILED. Terminal state는 다시 열리지 않는다.

Idempotency

unique(owner, operation, key). 같은 request hash는 기존 job, 다른 payload는 409.

Lease claim

FOR UPDATE SKIP LOCKED와 bounded heartbeat.

Fencing

모든 event, terminal update, artifact publish에 current token 요구.

Owner scope

모든 조회·취소·다운로드 query에 owner predicate 요구.

Fail-closed: 만료된 worker가 늦게 성공해도 stale fencing token으로 결과 상태나 artifact를 공개할 수 없다.

3A. Bounded schema normalization contract

OpenAPI 3.0.x와 3.1.x를 같은 canonical Tool schema로 정규화하고, 모호하거나 무제한인 계약은 endpoint별 이유와 함께 차단한다.

Schema familySupported boundaryFail-closed boundary
Nullable inputsOptional query/header null은 wire에서 생략. Nullable root body는 absent와 JSON null을 구분.Nullable path와 Required nullable query/header
Array constraintsmaxItems <= 256. uniqueItems는 bounded structural equality로 검증.명시적 bounded maxItems가 없는 uniqueness
CompositionCompatible object allOf, branch 8 이하 oneOf·anyOf·multi-type.Conflict, empty composition, depth 16 또는 total branch 64 초과
ReferencesNon-recursive local reference와 semantic OpenAPI 3.1 $ref sibling.Remote/recursive reference, discriminator, custom dialect
공통 실행 경계: CLI representative call, 생성된 Spring AI 서버, Runtime Metadata, Managed Runtime은 같은 schema 의미를 검증하며 실패한 입력은 provider 요청 전에 차단한다.

4. Generation sandbox and recovery

OpenAPI parse부터 generated application/MCP validation까지 하나의 임시 job container에서 수행한다.

Linux single host

Control plane과 execution plane의 OS user, socket, volume을 분리.

apps/worker + rootless Docker socket

DB lease, container lifecycle, heartbeat, bounded result collection.

Digest-pinned runner image

CLI, JDK 17/21, Gradle 9.6.1, approved profile cache.

Ephemeral workspace

Generate, compile/test, app/MCP validation, artifact allowlist, complete cleanup.

Network

network=none. Mock upstream은 container loopback.

Identity

Numeric non-root, cap drop all, no new privileges, no Docker socket.

Filesystem

Read-only rootfs, bounded tmpfs/workspace, controlled copy.

Resources

CPU 2, memory 4 GiB, PID 256, wall timeout 10 minutes.

Dependencies

Gradle offline. Cache miss는 runner provisioning failure.

Output

Path/type/symlink/size/checksum allowlist 후 private upload.

Crash recovery

1. Claim

새 fencing token과 container job/attempt/token labels.

2. Lease expiry

잔존 labeled container를 bounded stop/remove하고 retry 후보로 복구.

3. Retry / fence

새 token으로 재시도. 이전 worker terminal write와 publish는 거부.

5. Hosted API/UI and compatibility

Thymeleaf UI와 same-origin API를 Spring Security OIDC, CSRF, owner-scoped repository 위에 구성한다.

TLS reverse proxy

유일한 public endpoint. 외부 forwarding headers 제거 후 trusted values 생성.

OIDC login

Issuer + subject를 account UUID로 매핑. Session rotation과 CSRF.

Owner-scoped Web

Dashboard, import, generation, job history, authorized artifact stream.

Public exposure gate: local filter를 느슨하게 바꾸지 않는다. hosted configuration은 OIDC, DB, private storage, Worker, trusted proxy 검증이 하나라도 실패하면 startup을 거부한다.
