OpenAPI to MCP

Gen2Spring MCP

필요한 API endpoint만 선택해 검증 가능한 Spring MCP 서버를 생성합니다.

작업 내역

입력 내용을 확인해 주세요

STEP 1

1. OpenAPI 파일

YAML, YML, JSON · 최대 10MB

파일을 선택하거나 끌어놓기 OpenAPI 문서를 이 영역에 놓으면 바로 분석합니다.

분석할 OpenAPI 파일을 선택해 주세요.

STEP 2

2. API endpoint 선택

MCP Tool로 만들 endpoint

파일 분석 후 endpoint를 선택할 수 있습니다.

    검색 조건에 맞는 endpoint가 없습니다.

    STEP 3

    3. 생성 설정

    프로젝트와 Tool 세부 설정을 확인한 뒤 미리보기합니다.

    호환 프로필을 불러오는 중입니다.

    선택한 MCP Tool

    행을 펼쳐 기본 이름과 고급 정책을 조정할 수 있습니다.

    Step 2에서 endpoint를 하나 이상 선택해 주세요.

    Tool 설정
    고급 Tool 정책

    Retry policy

    Pagination policy

    Parameter sources

    Response normalization

    STEP 4

    4. 미리보기와 생성

    대표 호출로 설정을 검증한 뒤 프로젝트를 생성합니다.

    대표 호출과 미리보기

    생성 전 미리보기가 필요합니다.

    STEP 5

    5. 생성 진행

    생성과 검증이 끝나면 산출물을 내려받을 수 있습니다.
