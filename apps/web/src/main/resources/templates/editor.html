      Tool 세부 설정이름과 실행 정책을 편집합니다. 왼쪽에서 Tool을 선택하세요. 접기 열기
      선택한 Tool 설정
      일시적인 실패를 자동으로 다시 요청합니다.

      429·503 응답이나 네트워크 오류에 사용할 수 있습니다. 재시도 횟수와 시도 사이의 대기 시간을 제한해 무한 반복을 방지합니다.

      Retry-After를 켜면 서버가 알려준 대기 시간을 우선 반영합니다.
      여러 페이지의 결과를 한 번의 Tool 호출로 모읍니다.

      응답의 다음 cursor를 요청 파라미터에 넣어 반복 호출합니다. Items와 Next value 경로는 JSON Pointer로 지정합니다.

      최대 페이지 수와 항목 수가 반복 호출의 종료 한계입니다.
      요청 파라미터 값을 어디에서 받을지 정합니다.

      User input은 Tool 호출자가 값을 전달합니다. Server secret은 서버 환경 변수에서 값을 읽어 호출자에게 노출하지 않습니다.

      API key나 내부 토큰처럼 사용자가 직접 입력하면 안 되는 값은 Server secret을 사용합니다.

      파라미터마다 사용자 입력 또는 서버 환경 변수를 선택하세요.

      서로 다른 API 응답을 일관된 결과로 정리합니다.

      데이터, 성공 코드, 오류 메시지, 전체 개수의 위치를 JSON Pointer로 지정합니다. 예: /data/items

      별도 정규화가 필요하지 않으면 비워 두어 원본 응답을 사용합니다.

      필요한 값만 지정하고 나머지는 비워 둘 수 있습니다.
